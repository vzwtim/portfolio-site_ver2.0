# About / Gallery / Works 改善案

ホームの「静かな背景モーション」「面全体を押せるカード」「余白を活かした編集的レイアウト」を、下層ページにも一貫して展開する。

## About

- 冒頭を短いステートメントと人物写真の二層構成にし、スクロールに合わせて経歴・関心領域を順に開示する。
- 経歴を単純な年表ではなく「観察する / 読み解く / 形にする」の3つの姿勢で再編集し、関連作品へ接続する。
- スキルチャートは数値の自己評価よりも、実務での使い方と成果物が分かるケースリンク中心にする。

## Gallery

- 写真を均一なサムネイル一覧にせず、縦横比と余白にリズムを持たせたエディトリアル・グリッドにする。
- ホバー時はわずかな被写界深度・タイトル・撮影地を重ね、クリックすると背景色を抑えた没入型ビューアへ遷移する。
- 「地域 / 建築 / 移動 / 生活」の切り口で絞り込み、作品ページのフィールドワークと相互リンクする。

## Works

- 一覧の冒頭に分野横断フィルターを置き、「不動産・建築 / 文化・企画 / DX・デジタル」というホームの分類を引き継ぐ。
- 各カードは画像面全体をリンクにし、役割・期間・成果を短く表示する。ホバー表現もホームと統一する。
- 詳細ページは「課題 / 観察・調査 / 判断 / 制作 / 結果」の順で読み進められるケーススタディ形式にする。
- 次の作品への導線をページ末尾だけでなく、本文中の関連テーマにも設けて回遊性を高める。

## 共通方針

- 装飾線・パターン・軌道は必ず本文と画像の背面に置き、可読性と操作性を優先する。
- Intersection Observer による一度だけの表示演出を基本とし、`prefers-reduced-motion` では停止する。
- タッチ、キーボード、マウスのどれでも同じ遷移先へ到達できるよう、見た目だけのホバー操作を作らない。
